# GraverBurg Architecture & Developer Guidelines

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS + Custom Design Tokens in `src/index.css`
- **Aesthetic**: Matte Charcoal `#0D0E12`, Pistachio Lime `#D6F174`, Honey Yellow `#F7C948`, Coral Tangerine `#FA5D54`. Zero glassmorphism.
- **Components**: Located in `components/`
- **State & Mock Data**: `lib/mockData.ts` & `components/ToastContext.tsx`
- **Entry Points**: `index.html` -> `src/main.tsx` -> `src/App.tsx`
